# Shared layouts

## Main layout

`src/app/(main)/layout.tsx` wraps authenticated/public application routes. It loads the Newsreader display font, renders `Header` inside a Suspense boundary, and centers page content in a flex column with `gap-6 p-6 pt-36`.

```tsx
import type { Metadata } from "next";
import { Newsreader } from "next/font/google";
import { Suspense, cache } from "react";
import Header from "@/components/header";
import { UserProvider } from "@/providers/UserProvider";
import { getCurrentUserSession } from "@/services/users/service/getCurrentUser.service";
const newsreader = Newsreader({ subsets: ["latin"], weight: ["400", "600", "700"], variable: "--font-auth-display", display: "swap" });
export const metadata: Metadata = { title: "Nosso TBR", description: "Generated by create next app" };
const getCachedSession = cache(async () => await getCurrentUserSession());
export default async function MainLayout({ children }: Readonly<{ children: React.ReactNode }>) {
  const session = await getCachedSession();
  return <UserProvider initialUser={session?.user ?? null} initialTier={session?.tier ?? null}><div className={newsreader.variable}><Suspense fallback={<svg className="mr-3 size-5 animate-spin ..." viewBox="0 0 24 24" />}><Header /></Suspense><div className="flex flex-col items-center gap-6 p-6 pt-36">{children}</div></div></UserProvider>;
}
```

## Header

`src/components/header/header.tsx` is the shared top navigation. Its responsive branch uses `navMenu`, `homeSearchBar`, account menu, and a mobile extended menu. Preserve the existing brand logo, active navigation state, and account actions. The target issue is mobile content obstruction, not a reason to redesign the desktop shell.
