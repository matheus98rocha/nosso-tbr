# Domain docs

Este é um repositório single-context.

## Antes de explorar

- Ler `CONTEXT.md` na raiz, se existir.
- Ler ADRs relevantes em `docs/adr/`, se existirem.
- Se esses arquivos não existirem, prosseguir silenciosamente.

## Estrutura esperada

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

Usar a terminologia definida no glossário quando ele existir. Se um conceito necessário não estiver documentado, sinalizar a lacuna para a skill de modelagem de domínio.
